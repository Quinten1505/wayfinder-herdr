# Agent instructions

## Agent skills

Before creating, claiming, resolving, or querying tickets, maps, or specs, read [the GitHub tracker conventions](docs/agents/issue-tracker.md). GitHub Issues is canonical; the old `.scratch/` paths are migration pointers.

Before changing domain terminology, read [CONTEXT.md](CONTEXT.md) and use the domain-modeling skill. Keep it a glossary; design decisions belong in their tickets.
