# Wayfinder for herdr

A planned Rust plugin for a single orchestrating chat in herdr to coordinate decision tickets, implementation agents, independent reviewers, and Git worktrees.

- [Decision map](https://github.com/Quinten1505/wayfinder-herdr/issues/1)
- [Draft specification](https://github.com/Quinten1505/wayfinder-herdr/issues/10)
- [Issue tracker conventions](docs/agents/issue-tracker.md)

Current status: planning and primary-source research. The plugin has not been implemented yet.
