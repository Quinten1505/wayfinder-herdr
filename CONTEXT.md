# Wayfinder orchestration

A shared decision map guides an effort toward its destination. The human participates through one orchestrating chat while delegated work advances the map.

## Language

**Map**: The shared index of an effort's destination, resolved decisions, remaining fog, and scope boundaries.

**Decision ticket**: A question whose resolution makes the route to the destination clearer.

**Frontier**: The open, unclaimed tickets whose blocking tickets are resolved.

**Orchestrator**: The agent coordinating the map and delegated work through the human's single chat.

**Implementation instance**: A delegated agent session carrying out authorized execution work for an effort.

**Reviewer**: An agent that independently evaluates an implementation and reports findings before the human decides whether to merge it.

**Execution override**: An explicit map preference extending an effort beyond decisions to delivery.
